# Backend Review Flow

1) Map Kratos layers and DI wiring.
2) Review auth, tenant isolation, and RBAC enforcement.
3) Inspect data layer for query safety and transactions.
4) Check API contract consistency and error mapping.
5) Verify migrations and schema safety.
6) Validate observability (logs, tracing, metrics).
7) Assess performance (pagination, export, timeouts).
8) Provide prioritized findings and fixes.
