# Frontend Review Flow

1) Identify page routes, shared UI, and data access layers.
2) Verify App Router patterns and client/server boundaries.
3) Check shadcn/ui usage and design consistency.
4) Audit Handsontable integration and dynamic imports.
5) Validate loading, error, and empty states.
6) Check accessibility and keyboard navigation.
7) Review performance: large lists, memoization, bundle size.
8) Provide prioritized findings and remediation steps.
