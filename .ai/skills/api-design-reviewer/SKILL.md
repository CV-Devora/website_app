# api-design-reviewer

## Purpose
Ensure consistent API contracts and versioning.

## Responsibilities
- Contract consistency
- Pagination and filtering
- Error envelopes

## Workflows
1) Review endpoint naming and parameters.
2) Standardize response envelopes.
3) Validate pagination strategy.

## Review Checklist
- Consistent status codes
- Stable error shapes
- Backward compatibility

## Implementation Standards
- Use typed DTOs
- Avoid breaking changes

## Anti-Patterns
- Mixed query/body conventions
- Unbounded list responses

## Production Rules
- Versioned APIs
