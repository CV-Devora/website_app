# code-reviewer

## Purpose
Perform strict, production-grade code reviews.

## Responsibilities
- Identify defects and risks
- Enforce standards
- Ensure test coverage

## Workflows
1) Review changes for correctness and security.
2) Check for regressions and edge cases.
3) Require tests and documentation.

## Review Checklist
- Error handling consistency
- Security-sensitive changes flagged
- Adequate tests

## Implementation Standards
- Provide actionable fixes
- Rank findings by severity

## Anti-Patterns
- Approving without tests
- Ignoring migration impact

## Production Rules
- No silent failure paths
