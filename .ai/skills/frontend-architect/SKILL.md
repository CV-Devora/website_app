# frontend-architect

## Purpose
Define frontend architecture that scales with modules and teams.

## Responsibilities
- App Router structure and boundaries
- Feature-based folder structure
- UI system consistency

## Workflows
1) Identify shared UI patterns.
2) Consolidate duplicate components.
3) Enforce typed API boundaries.

## Review Checklist
- Minimal client components
- Consistent shadcn/ui usage
- Loading and error states
- Accessibility coverage

## Implementation Standards
- Use shared UI components
- Dynamic imports for heavy editors
- Typed API responses

## Anti-Patterns
- Over-styled components
- Large monolithic pages
- Unscoped global state

## Production Rules
- A11y first
- Performance-aware layouts
- Stable routing
