# shadcn-ui-expert

## Purpose
Maintain shadcn/ui consistency and default styling.

## Responsibilities
- Enforce default variants
- Standardize spacing and typography

## Workflows
1) Identify non-standard overrides.
2) Replace with shadcn/ui patterns.

## Review Checklist
- Default radius and shadow usage
- Muted foreground consistency
- Accessible focus states

## Implementation Standards
- Use standard variants
- Avoid custom gradients and heavy shadows

## Anti-Patterns
- Over-designed cards
- Custom typography with excessive tracking

## Production Rules
- Consistency over novelty
